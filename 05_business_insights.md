# Procurement Spend Analytics — Business Insights

## 1. Project Overview

This project analyzes sample procurement data using SQL to understand
spending patterns, supplier performance, and delivery reliability.

The dataset contains suppliers, products, purchase orders, and delivery
records. All records are synthetic and created for demonstration purposes.

## 2. Key Business Questions

- What is the total procurement spend?
- Which suppliers account for the highest spend?
- How does spending change month by month?
- Which deliveries arrived late?
- How reliably do suppliers deliver on time?
- Which purchase orders remain open?

## 3. Expected Business Value

### Spend Visibility
Analyze order values by supplier and month to help identify major
spending areas and opportunities for cost review.

### Supplier Performance
Compare on-time delivery rates to identify suppliers that may need
performance discussions or improvement plans.

### Delivery Risk
Identify late deliveries and open purchase orders so procurement teams
can investigate potential supply delays.

### Data Quality
Run validation checks to identify missing values, invalid quantities,
incorrect references, and inconsistencies in delivery records.

### Reconciliation
Compare record counts and calculated order values to help verify that
data has been loaded and reported consistently.

## 4. Recommendations

1. Review high-spend suppliers for potential savings opportunities.
2. Discuss recurring late deliveries with the relevant suppliers.
3. Monitor open purchase orders against expected delivery dates.
4. Investigate data-quality exceptions before publishing reports.
5. Reconcile source and target record counts during data migration.
6. Retest key business scenarios during user acceptance testing (UAT).

## 5. Tools and Skills Demonstrated

- SQL and relational database concepts
- Joins, aggregations, filtering, and date calculations
- Procurement spend analysis
- Supplier performance reporting
- Data quality validation
- Data reconciliation concepts
- Business analysis and documentation

## 6. Important Note

This is a learning project using synthetic data. The findings are
illustrative and do not represent any real company or client.
